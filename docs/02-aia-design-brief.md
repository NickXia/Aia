# Aia 设计纲要 v1

> 依据：`docs/01-via-deconstruction.md`。这份纲要只做一件事——把 Via 的**结构经验**翻译成鸿蒙上可执行的规格，并标出上一版工程与它的实际差距。

---

## 0. 定位

**Aia 是鸿蒙上"默认只留一条工具栏"的浏览器：首屏没有信息流，没有推荐位，没有第二排图标；需要的能力全在，但都藏在一次点击之内。**

不做的事先写清楚：不做内容分发、不做新闻流、不做账号体系（v1）、不做内核。

---

## 1. 三条不可妥协的结构决定

### 决定一：一条常驻工具栏，其余全部是覆盖层

- 工具栏固定在底部，**只有一行**，高度 52vp，5 个槽位：后退 / 前进 / 地址胶囊 / 标签数 / 菜单。
- 主页**不放第二个搜索框**：地址栏就在拇指边，重复入口只会制造选择成本。
- 所有面板（菜单、标签、书签历史、设置）都是**同页覆盖层**，不跳路由、不压栈——这样切换零等待，也回避了鸿蒙路由返回栈与网页后退栈打架的问题。
- 覆盖层打开时，工具栏保持在原位不隐藏（Via 也不隐藏），视觉上"面板从工具栏长出来"。

### 决定二：用系统 ArkWeb，不打包内核

- 这是 2.5 MB 的同构选择。鸿蒙侧对应能力：`@kit.ArkWeb` 的 `Web` 组件 + `WebviewController`。
- 代价要认：网页兼容性与 WebView 版本绑定，某些站点特性可能缺失。产品文案里不承诺"最强兼容性"。
- 收益：启动无内核加载、包体可控、系统级安全更新。

### 决定三：默认值克制 + 一张 Action 表

- 所有可触发动作定义成枚举：`none / reload / scrollTop / inputUrl / bookmarks / history / closeTab / prevTab / nextTab / back / forward`。
- 按钮点击、按钮长按、滑动手势三处**都从这张表取值**，不各写一套。
- 好处：v1 只暴露"点击"，v2 加手势和长按不需要改 UI 结构，只加映射。

## 2. 与现有工程的差距（诚实清单）

上一版工程是在这份研究之前写的，方向对、密度不够。逐项对照：

| 项 | 现状 | 差距 | 优先级 |
| --- | --- | --- | --- |
| 单行底部工具栏 | 已有 | 无自动隐藏；无安全区适配校验 | P1 |
| 主页（标识 + 快捷方式 + 最近） | 已有，快捷方式**硬编码** | 快捷方式不可编辑/增删，违背 Via 的"收藏墙可自定义" | P1 |
| 多标签 + 独立 WebviewController | 已有 | 标签面板无缩略图、无长按关闭、无"关闭其他" | P2 |
| 地址栏智能识别 | 已有 | 无编辑态历史/书签联想下拉 | P1 |
| 菜单 | 8 项固定 | 缺关键动作：**页内查找 / 请求桌面版 / 无图模式 / 分享 / 添加到桌面**；不可自定义 | P0 |
| 设置 | 仅 6 项（引擎/主页/无图/历史/JS/DNT） | 缺分组结构、缺隐私三项（拦截/追踪/Cookie）、缺 UA、缺工具栏与手势 | P0 |
| 广告拦截 | **没有** | 需 `onInterceptRequest` + CSS 注入两条腿 | P0 |
| 页内查找 | **没有** | ArkWeb 无稳定原生 API，需 JS 注入实现 | P0 |
| 无痕模式 | **没有** | `Web` 的 `incognitoMode` 属性可用 | P0 |
| 手势（滑动返回/前进） | 没有 | 需自实现，注意与系统侧滑返回冲突 | P1 |
| 下载 / 资源嗅探 | 没有 | `onDownloadStart` + `@ohos.request` | P2 |
| 用户脚本 | 没有 | v2 议题（安全模型要重新设计） | — |
| 书签/历史导入导出 | 没有 | 影响"换机不丢书签"这个核心诉求 | P1 |

**结论：方向不用推翻，但 v1 若不补 P0 四项（查找 / 桌面版 / 无痕 / 设置分组 + 拦截），Aia 只是"长得像 Via"，用起来不像。**

## 3. v1 范围

**必须有**

1. 单行工具栏 + 工具栏点击态与禁用态
2. 地址栏四态：空态 / 编辑态 / 加载态（进度条）/ 完成态（锁 + 域名）
3. 主页：标识、可编辑快捷方式墙（8 格，长按进入编辑）、最近访问 5 条
4. 多标签：面板、新建、关闭、切换、关闭全部
5. 菜单：页内查找、请求桌面版、无图模式、分享、加书签、书签、历史、刷新、设置、关闭标签（两行网格，不折叠二级）
6. 设置分组：通用 / 外观 / 隐私 / 关于
7. 页内查找条（底部升起，上一个/下一个/计数/关闭）
8. 无痕标签（图标提示 + 不写历史、不落 Cookie）
9. 广告拦截：请求级 + 元素级，可一键关闭
10. 书签/历史 HTML 导出导入
11. 深浅色跟随系统 + 手动覆盖

**明确不做（避免范围失控）**

用户脚本、云同步、账号、阅读模式、翻译、下载管理器 UI（先只做系统下载跳转）、平板双栏布局、皮肤系统。

## 4. 关键交互规格

### 4.1 工具栏宽度预算（360vp 基准）

| 槽位 | 宽度 | 说明 |
| --- | --- | --- |
| 后退 / 前进 | 各 40 | 不可用时降到 30% 透明度，保留占位不塌陷 |
| 地址胶囊 | 剩余自适应（≥140） | 编辑态时其余按钮让位，胶囊吃掉整行 |
| 标签数 | 40 | 角标最多两位数，>99 显示 99+ |
| 菜单 | 40 | 固定最右 |

间隙 2vp，左右边距 6vp。**编辑态切换用宽度动画（220ms）而非淡入淡出**，避免输入时视觉跳动。

### 4.2 地址栏四态

| 态 | 显示 | 进入条件 | 退出 |
| --- | --- | --- | --- |
| 空态 | 灰色占位"搜索或输入网址" + 刷新图标 | 新标签页 | 点击 |
| 编辑态 | 输入框 + 全选 + "取消" + 键盘 | 点击胶囊 / 长按 | 回车 / 取消 / 失焦 |
| 加载态 | 域名 + 进度条（工具栏顶部 2vp） | 开始加载 | 加载完成 |
| 完成态 | 锁图标（安全）/ 站点信息图标 + 域名 | 加载完成 | 点击 |

规则：编辑态回车时，若输入含空格或无点号 → 走搜索引擎；含点号或以 `http(s)://` 开头 → 当域名；`localhost:xxxx` → 补 `http://`。

### 4.3 返回键优先级（严格自上而下）

1. 编辑态 → 退出编辑
2. 页内查找条 → 关闭查找
3. 任何覆盖层 → 关闭覆盖层
4. 网页可后退 → 网页后退
5. 当前为网页 → 回主页
6. 否则 → 退出应用

这条链路要写死在一个函数里，不要分散到各组件，否则必然出现"要按两次才退出"。

### 4.4 菜单

两行 × 5 槽的网格，图标 20、文字 11，不滚动、不分页。Via 的做法是**一屏放下，不做二级菜单**——这是"少一次点击"的具体兑现。

### 4.5 标签面板

一列卡片（标题 + 域名 + 缩略图占位），当前标签描边高亮。顶部左"标签"右"新建"，底部左"关闭全部"右"完成"。

### 4.6 主页

标识 28vp 字重 600 + 8 格快捷方式（44×44 圆角 14）+ "最近访问"5 条单行。整体垂直居中偏上，留白大于内容——留白本身就是极简的表达。

## 5. 鸿蒙技术映射（ArkWeb）

| 需求 | 接口 | 备注 |
| --- | --- | --- |
| 多标签隔离 | 每标签独立 `WebviewController`，`visibility` 切换 | 不销毁组件以保滚动位置 |
| 加载进度 | `onProgressChange` / `onPageBegin` / `onPageEnd` | 进度值驱动顶部 2vp 条 |
| 标题回填 | `onTitleReceive` | 空标题保留域名 |
| UA 切换 | `setCustomUserAgent` | 桌面版 = 追加 Desktop UA |
| 无图模式 | `setImageAccess(false)` / `setOnlineImageAccess(false)` | 即时生效需刷新 |
| 无痕 | `Web({ ..., incognitoMode: true })` | 需确认当前 SDK 版本签名 |
| 深色网页 | `setDarkMode` + `setForceDarkAccess` | 跟随系统 |
| 页内查找 | `runJavaScript` + `window.find` 或自绘高亮 | 无稳定原生 API，按注入方案实现 |
| 广告拦截（请求级） | `onInterceptRequest` 返回空/自定义响应 | 主线程回调，规则匹配要转成集合查表，别做正则遍历 |
| 广告拦截（元素级） | 页面注入 CSS：`[class*="ad-"], ins.adsbygoogle {display:none}` | 与请求级互补 |
| 下载 | `onDownloadStart` + `@ohos.request` | v1 只跳系统下载 |
| 工具栏滚动隐藏 | `onScroll` 的 `yOffset` 方向判断 | 阈值合并抖动，别逐帧触发 |
| 沉浸式 | `windowClass.setWindowLayoutFullScreen` + 安全区 insets | 底部 insets 加进工具栏 padding |
| 持久化 | `preferences` 封装（现有 `Storage.ets`） | 分组键前缀：`general.* / look.* / priv.*` |

> 标注：以上为按 ArkWeb 公开能力设计，具体方法名与参数以本机 SDK 声明文件为准；`incognitoMode`、`setForceDarkAccess` 在不同 API 版本上的可用性需在首次编译时确认。

## 6. 视觉 token（沿用现有 `AiaTheme.ets` 思路）

| token | 值 | 用途 |
| --- | --- | --- |
| 主文字 | `#111114` / 深色 `#F2F2F5` | 标题、地址 |
| 次文字 | `#8A8A8F` / `#8E8E93` | 占位、副标题 |
| 分隔线 | `#EBEBEF` / `#26262B` | 0.5vp 发丝线 |
| 面板底 | `#FFFFFF` / `#17171A` | 覆盖层 |
| 强调 | `#2A6BFF` | 仅用于进度条与选中态，不做装饰 |
| 圆角 | 胶囊 100 / 面板 24 / 图标底 14 | 三档，不再加 |
| 字号 | 11 / 12 / 13 / 17 | 四档，不再加 |

原则：**颜色不超过 5 个语义位，圆角不超过 3 档，字号不超过 4 档。** 超出即为失控。

## 7. 验收标准

1. 冷启动到可输入：≤ 800ms（中端机）
2. 从点击图标到网页首屏：无白屏空转，进度条 200ms 内出现
3. 切标签 10 次后，返回首个标签仍保持原滚动位置
4. 五个覆盖层依次开关，无一次白屏、无一次 200ms 以上卡顿
5. 断网访问任意站点：显示错误页而不是空白
6. 系统切深色后，工具栏、面板、主页三层同步变色，无残留亮色
7. 页内查找命中 3 处以上时，计数正确、上下跳转不丢焦点
8. 返回键在六种状态下行为与 4.3 完全一致
